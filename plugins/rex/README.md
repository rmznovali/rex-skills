# rex plugin

SEO made simple.

rex gives your agent real SEO data and guided workflows, so its advice is grounded in your website instead of generic recommendations.

## What you can do

- Find and evaluate keywords
- Research competitors and content gaps
- Audit a website and prioritize fixes
- Analyze backlinks and find link prospects
- Track organic and Google Maps rankings
- Work with Google Search Console and Analytics data
- Research AI prompts and track brand mentions, citations, and competitors

The plugin includes twelve skills that guide your agent through complete SEO workflows, plus the hosted rex MCP server for live data and project management.

## Connect

In Claude Code, run `/plugin install rex --marketplace rmznovali/rex-skills`. For other agents, see the main README. The first time your agent uses a rex tool, follow the OAuth prompt to sign in and approve the connection. There is no API key to configure.

To check the connection without using credits, ask: "Use rex to check my connection and list my projects."

You need a rex account. Plans are described at [rexmetrics.com](https://www.rexmetrics.com).

## Try it

- "Research keywords for my website and shortlist the best opportunities."
- "Audit my website and tell me what to fix first."
